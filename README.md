# 绘图脚本项目说明

本项目为文章配图绘制脚本，包含多个图表的 Python 绘图脚本。

## Python 环境

- Python 版本：3.1.2

### 所用第三方库

| 库名 | 用途 |
| --- | --- |
| pandas | 数据读取与处理 |
| numpy | 数值计算 |
| matplotlib | 图表绘制（散点图、柱状图、直方图、热图、火山图等） |
| seaborn | 热图与聚类、箱线图与散点图叠加 |
| scikit-learn | PCA 降维分析、数据标准化 |
| scipy | 数据平滑插值（样条曲线） |
| upsetplot | UpSet 集合图绘制 |

### 标准库

argparse、math、os、warnings、collections

## 其他图片绘制工具

除上述 Python 脚本外，文章中其他图片绘制还用到了以下工具：

- **Cytoscape**：网络图绘制
- **R 4.5.3**：统计分析与图表绘制
- **微生信云平台**：在线生物信息学图表绘制
- **Adobe Illustrator**：图形后期排版与美化
